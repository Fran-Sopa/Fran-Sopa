# Francisco García Domene

I build the [Prisma Reviews API](https://prismareviews.com/) at Sopa Lab: one review API for 84 platforms, with webhooks, replies by official API where allowed, and an MCP server for AI agents. One key, one JSON format.

- [n8n-nodes-prisma-reviews](https://github.com/Fran-Sopa/n8n-nodes-prisma-reviews): the n8n node for the Prisma Reviews API, verified by n8n
- [prisma-reviews-examples](https://github.com/Fran-Sopa/prisma-reviews-examples): code examples for the API
- [MCP server](https://prismareviews.com/docs/mcp): ask Claude, Cursor or ChatGPT about your reviews
- [State of review platform APIs 2026](https://prismareviews.com/guides/state-of-review-platform-apis-2026): which review platforms have an API, which allow replies, with an open dataset

Docs: [prismareviews.com/docs](https://prismareviews.com/docs)
